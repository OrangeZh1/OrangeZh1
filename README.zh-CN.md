## 🌱 从好奇开始

<details>
<summary><strong>更多关于我</strong></summary>

<p>嗨，我是橙子 🍊，2005 年出生，从小学时期就开始接触互联网。各种网站、软件和新工具总能勾起我的好奇：<strong>它是怎么做出来的？我又能用它做点什么？</strong></p>

<p>2021 年，我开始顺着这些好奇去学技术、写代码。后来做过博客、网站，也做过小程序。我很喜欢一个想法终于变成能点、能用的东西的那一刻，也喜欢在第一版之后，继续琢磨怎么让它更好用。</p>

<p>现在，我把更多精力放在<strong>商业软件和 AI 产品</strong>上。QiCore 是我想长期打磨的一条主线，希望通过真实应用不断完善这套框架。围绕 QiSSO、电商设计、Image2、证件照、校园零食，以及正在设计的 AI SCRM，我也在一点点把不同的业务需求做成产品。</p>

<p>做界面时，我用过 React、Vue、Nuxt；写后端时，会接触 PHP、Node.js 和 Go；再用 MySQL、Docker、Nginx 等工具把各个部分连接起来。我喜欢带着项目学技术：遇到问题就去试、去理解，再把做过的东西慢慢打磨好。🛠️</p>

<p>最近也在继续探索 AI、Vibe Coding 和可复用的 Skill。一边完善 QiCore 和手里的应用，一边希望把博客和自媒体持续做起来，分享<strong>做了什么、试过什么、在哪里卡过，以及最后学到了什么</strong>。如果你也喜欢折腾技术、做点自己的东西，欢迎来交流。👋</p>
